Batasan RemoteViews yang dihormati

  • Semua varian hanya pakai LinearLayout + TextView + ImageView + View — tidak ada custom view, tidak ada blur/shadow.
  • Font di widget asli Android adalah font sistem (Poppins/JetBrains Mono di mockup ini hanya pendekatan visual).
  • Sudut membulat & pil lewat shape drawable XML; warna dot tetap via setColorFilter seperti sekarang.
  • Kontrak id lama (w_header, w_add, w_empty, w_row{n}_*) dipertahankan — provider Kotlin hanya tambah id baru, tak perlu tulis ulang.
Contoh data: 07.30 Algoritma (rutin), 10.00 Bimbingan skripsi (jadwal), 13.00 Basis Data (rutin), 16.00 Kumpul tugas Struktur Data (tugas), 19.00 Rapat himpunan (jadwal).

Kalau sudah pilih, implementasinya

  1. Duplikat widget_agenda.xml → layout varian terpilih (id lama dipertahankan).
  2. Tambah drawable: widget_next_bg.xml (A) / widget_bg_light.xml (B) / reuse widget_dot.xml sebagai bilah (C).
  3. Update AgendaWidgetProvider.kt: isi w_count/w_date/w_row{n}_sub|tag, sorot baris pertama.
  4. Opsional: kecilkan horizon payload 8 hari → 1 hari (Kotlin selama ini memfilter ulang hanya hari ini).
Mockup ini pratinjau visual saja — belum mengubah kode. Balas dengan “A”–“F” (mis. “D”, atau “mix E+A”) dan saya implementasikan ke XML + Kotlin + tes payload.
